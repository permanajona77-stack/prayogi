# GAMEN GEAR – Gaming Store

Website katalog sederhana untuk produk **ONESOS SY830 Gaming Headset**. Dibuat menggunakan HTML, CSS, dan JavaScript tanpa framework.

## Fitur
- Desain responsif untuk desktop dan perangkat mobile.
- Navigasi ke bagian Beranda, Produk, Tentang, dan Kontak.
- Informasi dan spesifikasi produk.
- Pencarian produk.
- Keranjang belanja dengan pengaturan jumlah barang.
- Checkout yang menyiapkan pesan pesanan melalui WhatsApp.
- FAQ interaktif.

## Cara menjalankan
1. Unduh atau clone repository ini.
2. Buka file `index.html` menggunakan browser.
3. Tidak diperlukan proses instalasi atau build.

## Deploy menggunakan GitHub Pages
1. Buat repository baru di GitHub.
2. Unggah `index.html` dan `README.md` ke folder utama (root) repository.
3. Buka **Settings → Pages**.
4. Pada bagian **Build and deployment**, pilih **Deploy from a branch**.
5. Pilih branch `main` dan folder `/ (root)`, lalu klik **Save**.
6. Tunggu proses publikasi selesai. GitHub akan menampilkan alamat website pada halaman Pages.
